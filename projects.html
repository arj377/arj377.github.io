Bare-Metal ARM Motor Controller

Source ↗

A real-time motor-control system built from scratch on an ARM Cortex-M3 without an operating system or runtime. I implemented the startup path, linker-controlled memory layout, interrupt-driven execution, and direct register-level peripheral interfaces.

20 kHz PWM 100 Hz PID loop <1% steady-state error ±3,000 RPM
